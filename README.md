# 折影 · 扩展版

原创黑白浏览器视觉解谜游戏。十四道谜题，一间展开以后仍藏着秘密的纸屋。

**在线游玩：[进入折影](https://changer8844.github.io/zheying/)**

## 本地游玩

解压后，用 Chrome 打开 `index.html`，无需安装、注册或联网。保留同目录下所有 JavaScript 与 CSS 文件。

也可以在此文件夹运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765`。

## 怎么玩

- 前七关是入门。第七关展开四个纸角后，墙面和地板继续展开，露出新增区域；用场景下方左右箭头查看房间。
- 物件下方的小点提示当前可以进入的谜题。七个新关卡各自包含完整线索，不必跨物件寻找。
- 镶板、书页可以拖动交换，也可以依次点选两块。影箱通过底座上的圆形操作点选择或拖动构件。
- 转动、翻面、折叠等操作使用画面中的按钮。每关都有三级提示，最后一级提供从重置状态出发的完整解法。
- 新关可撤回最近 80 次操作，撤回记录随进度保存；重置只清除当前未完成关卡的布局和撤回记录，保留已完成关卡。
- 查看折纸背面是观察操作，翻回正面后再折叠。不同折法产生相同正确构图时也能完成。
- Tab 选择操作点，Enter 或空格激活；转动类按钮也支持左右方向键。Escape 取消拖动或回房间。
- 解开后保留正确构图，再回房间观察变化。白鸟在第十四关结束后飞走。

## 音乐与提示音

点击右上角菜单 → **系统设置**，分别调节背景音乐和提示音与纸声的音量。两者都可单独降到 0，并有提示音试听；顶部声音按钮可以全部静音。

音乐是本作原创的慢速合成旋律，由浏览器在本地生成，不读取外部音乐文件。点击开始后才播放；离开页面时静音，音量与静音偏好自动保存。所有谜题在静音状态下均可完成。

## 进度与旧版接续

进度保存在当前浏览器的当前网址。扩展版使用 `zheying.save.v2`，首次打开时会迁移有效的 `zheying.save.v1`，保留原存档。

旧版未通关玩家继续原关卡；已通关七关的玩家进入展开后的房间，第八关亮起。旧版结尾不会被误认为已完成十四关。

更换浏览器、网址或清除网站数据可能导致不能继续原进度。如果浏览器禁止保存，底部会明确提示；本次游玩仍可进行。重新开始需确认，清除扩展版进度但保留声音设置及独立的旧版存档。

## 版本与验证

当前版本：扩展版 v2.0.0，发布标签 `expanded-v2.0.0`。原七关简易版保留在 `simple-v1.0.0`。

运行规则检查：`node tests/logic.test.cjs`。可选浏览器检查需要 Playwright 与 Chrome，先启动上述本地服务，再运行 `node tests/browser.test.cjs`；可用 `PLAYWRIGHT_PATH` 指定已有 Playwright，`GAME_URL` 指定试玩地址，`TEST_OUTPUT_DIR` 指定截图与报告目录。

使用原生 JavaScript、SVG、CSS、Web Audio；无后端、构建步骤或运行时外部依赖。所有图形、谜题和旋律为本项目制作。抽象玩法参考 HER TREES 的观察、移动与组合思路，未使用原作素材或关卡文件。

新七关每关 5–8 分钟是设计目标，尚待首次玩家试玩校准。功能验收与难度体验分别记录，详见 QA.md。
