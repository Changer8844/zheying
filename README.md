# 折影 · 简易版

原创黑白浏览器解谜短篇。七道谜题，一间逐渐显露折痕的房间。

## 开始游玩

解压后，使用 Chrome 打开本文件夹中的 **index.html** 即可游玩，无需安装、注册或联网。

也可在这个文件夹内运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765`。

请保留 index.html、style.css、logic.js、game.js 四个文件在同一个文件夹中。它们也是静态网站部署所需的全部文件，没有构建步骤。

## 怎么玩

- 点击房间里的物体进入谜题；当前可以解开的物体下方有一个轻轻闪动的小点。
- 拖动纸片；翅膀与折角可以直接点击。悬纸可以拖动交换，也可以依次点选两片交换。
- 每关右上角有三级提示，可逐级展开。重置只还原当前未完成谜题，不影响此前进度。
- 键盘操作：Tab 选择对象；方向键移动纸片；Enter 或空格转动、折叠、选择；Escape 取消正在进行的拖动或回到房间。
- 解开后，正确构图会留下来。点击“回到房间”继续。已解开的谜题可回看。
- 右上角可关闭声音。所有谜题都能在静音下完成。

## 进度

进度自动保存在当前浏览器。刷新后点击“回到这个梦”继续。更换浏览器、更换试玩地址、清除网站数据，都可能使原存档不可用。

如果浏览器禁止保存，底部会显示“存档不可用 · 请勿关闭页面”；本次仍可正常游玩。

菜单中的“从头开始”需要再次确认，确认后才清除进度。

## 关于这个版本

版本：**简易版 v1.0.0**，2026-09-19。此版本作为七关浏览器游戏的简易版基线保存，发布标签为 `simple-v1.0.0`。

图形、场景、谜题代码与合成音效均在本项目中制作，无外部图片、字体、音频或网络依赖。设计参考 HER TREES 的视觉观察与物体组合思路，未使用其游戏素材、名称标志或关卡文件。

15–25 分钟是最初的体验设计目标，尚未通过首次玩家盲测确认。当前版本已经完成浏览器功能通关；难度与趣味性仍适合通过你的试玩继续调整。

技术检查结果见 QA.md。逻辑检查可运行 `node tests/logic.test.cjs`。
